# 07: Formatted answers

**What to build:** Answers render as formatted text rather than a wall of unstyled characters, so lists, headings, and code in a Response are legible.

**Blocked by:** 01 — Chat with a Local Endpoint

**Status:** ready-for-agent

- [ ] Formatted answers render as formatted text: lists, headings, emphasis, and links are visually distinct
- [ ] Code blocks in a Response are readable, and a snippet can be copied out of the Conversation
- [ ] Streaming still works with formatting — text renders progressively rather than appearing only once complete
- [ ] Long code blocks do not break the layout on a narrow window
- [ ] A malformed or partially-streamed Response does not break rendering or throw
